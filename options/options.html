Kept on this device only. It is never synced.

How to get a key

Create one in Google Cloud Console and enable "YouTube Data API v3". Restrict the key to that API, and leave "Application restrictions" on None, because this add-on's requests carry no website referrer. Watch this YouTube video for step-by-step guide.

Recommended: 1000 to 5000.

More

The higher, the more quota your API (Innertube or Data API) will be used, but it will be more accurate as it will fetch more comments (and/or replies).

Which comments are scanned first. It only matters when the scan stops before the end.

Replies cost extra requests for every thread that has them.

Recommended: 1000. Empty means no cap.

More

Every request costs 1 unit and the default allowance is 10,000 a day for the whole key. When the budget runs out the scan stops and keeps what it found. 1000 units read about 50,000 comments.

More

Instead of reading comments in order, it asks the Data API for each possible timestamp of the video ("0:07", "0:08", ...) and keeps what comes back. BEWARE, if you check this checkbox and use it on a popular MV with millions of comments, don't say I didn't warn you!!! it will completely lag the hell out of your browser

A finished scan is kept on this device, so reopening the video costs no requests.

More

It also survives restarting Firefox. New comments only show up once the saved scan expires or you clear it. A scan is saved only if it ended normally, and is reused only while the scan limit, order, source and budget are unchanged.
